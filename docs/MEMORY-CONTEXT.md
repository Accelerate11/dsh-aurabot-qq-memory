# 对话记忆与上下文改进

基于上游 `aureth-labs/dsh-aurabot-qq` 提交 `b3301f6b014016e141c07d266a716c0fea566aab`，不改变发送权限、网关登录或工具授权。

聊天中枢把用户原话和完成轮次的机器人回复保存到 `conversation-context/`，按人格标识与聊天标识分别建日志。原始日志是追加记录，checkpoint只保存可检查的元数据；异常日志不会静默清空。assistant原话始终保持来源角色，不能自动作为真人事实。

每轮优先使用当前问题；明确新主题时不扩展旧主题，省略说法可使用前几轮用户线索。检索结合BM25与多个线索的排序合并。当前问题的权重高于辅助线索，避免反复提及的旧话题挤掉明确的新问题。旧对话以有来源的JSON片段附在本轮输入末尾，完整片段有长度预算；近期记录只在会话恢复时补入，避免每轮重复粘贴。

片段按完整消息及序列化长度拆分，超长粘贴单独保存，避免它让相邻的小事实也被预算排除。原始追加日志不截断、不改写。

扩展的 `prompt` 事件新增 `recentMessages`；`api.core.hub.recentMessagesOf(chatId, limit)` 提供同一人格/聊天的近期原话。关闭 `conversationContext.enabled` 后不再自动记录或注入此类对话材料。此层只补充上下文；DSH宿主仍管理自己的整体模型窗口与压缩，不能把片段预算称为完整请求的token上限。

事实记忆按来源聊天过滤检索和对照候选；同一主体同一聊天的精确重复才自动合并。近似措辞中的否定不会被静默覆盖，重复观察不改变原事件的时间；修订保留旧版本。旧版本遗留的无聊天范围条目保留原先共享行为，不能承诺它们已自动变成私有；迁移时应审查这些旧资料。

本地验证包含：省略指代、新话题、跨重启召回长对话中间的原话、说话者归属、人格与会话隔离、证据预算、否定/更正，以及使用模拟OneBot和DSH的真实聊天调用路径。脚本化假模型按当前指令分派动作，历史数据保留在输入断言中，不作为新动作再执行。

设计依据：[Generative Agents](https://arxiv.org/html/2304.03442v2)的经验记录与动态检索、[LongMemEval](https://arxiv.org/html/2410.10813v2)的跨会话/更新/时间/不知道时处理，以及[Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/)对长窗口使用能力的限制。参数是工程选择，实际效果需要回归测试和具体聊天评估。
